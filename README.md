# FinWise Journey

Create a modern, responsive landing page for a web application called **FinMentor AI** (placeholder name).

## Goal

The landing page should clearly communicate that this platform helps users improve their financial literacy through personalized learning powered by AI.

Unlike traditional finance apps that only track spending, this platform analyzes a user's bank statement, identifies areas where they need improvement, and creates a personalized learning journey.

The primary CTA should encourage users to **Sign Up**.

## Features Section

Use attractive cards.

### Personalized Learning

AI analyzes spending habits and prioritizes topics you actually need.

Example:

If you're already good at saving, the platform teaches investments or debt management first.

---

### Learn Using Your Own Transactions

Lessons don't use generic examples.

Instead, every concept includes examples based on your own spending patterns.

---

### Adaptive Quizzes

Each lesson ends with 1–2 quick quizzes.

If you answer incorrectly, you'll review the concept before moving on.

---

### AI Financial Mentor

Ask questions anytime.

Examples:

"Why do I need an emergency fund?"

"Where am I overspending?"
